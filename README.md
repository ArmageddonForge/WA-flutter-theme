# WA flutter theme

A Flutter library with a set of controls mimicking WA's look and feel.

Storybook in [./storybook](./storybook); deployed at <https://armageddonforge.github.io/WA-flutter-theme/>.

WormNET Snooper in [./snooper](./snooper):

```sh
flutter run -d linux --dart-define=SNOOPER_ORIGIN=https://snoop.wormnet.net/snooper/
```
